# Contributing

1. Use JDK 17 or newer.
2. Run `./gradlew clean check build` before submitting a change.
3. Add or update tests for behavior changes.
4. Keep CLI output and exit-code behavior documented in the README.
5. Do not commit credentials, private URLs, generated build files, or user data.
6. Follow the [Code of Conduct](CODE_OF_CONDUCT.md) and report security issues
   according to [SECURITY.md](SECURITY.md).
